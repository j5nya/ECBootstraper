# Echocore Bootstrapper

The source is open so anyone can see what the bootstrapper does before running it.

## Requirements

- Windows
- .NET SDK 8.0 or newer, or Visual Studio 2022

## Building

1. Clone the repository.
2. Run `dotnet build -c Release`.
3. The exe is in `bin\Release`.

## About

Installs and updates the Echocore client, and launches games from the site.
